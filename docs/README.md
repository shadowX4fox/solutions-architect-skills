Start with the [project README](../README.md) for what Solutions Architect Skills is. These guides go deeper.

| Guide | Read it when |

| [Alia](ALIA.md) | You want the 3D command center, or the architecture as an MCP server in your IDE |
| [Institution packs](INSTITUTION_PACKS.md) | You are adding an organization's standards, capability frameworks, architecture types, skins or defaults |
| [Troubleshooting](TROUBLESHOOTING.md) | Something failed — organized by symptom |
| [Design notes](DESIGN_NOTES.md) | You want to know why a rule is what it is, and what measured it |

`plugins/<plugin>/skills/<name>/SKILL.md` for the others. Contributing: [CONTRIBUTING.md](../CONTRIBUTING.md).
