# Cross-Industry Capability Map

> Complete index of the 223 cross-industry Capabilities of Turbo EA Capabilities, arranged under 41 Capability Groups and 9 Domains. This file is the index: use it to answer questions that need a *complete* answer — every Capability in a Domain or Capability Group, or where a named Capability sits in the hierarchy. Descriptions and the finer capabilities each one includes live in the 9 per-Domain files linked below.

The map organises business capability that any enterprise has, whatever its industry, as a three-level chain: a Domain (the catalogue's macro capability, an executive grouping) contains Capability Groups (its L1 capabilities), which contain Capabilities (L2). A Capability is the unit an initiative is aligned to; the L3 capabilities beneath it are listed by name on its **Includes.** line.

Counts: 9 Domains, 41 Capability Groups, 223 Capabilities, 893 included (L3) capabilities.

Entry format in the Capabilities section below: `[Capability](file#anchor): Domain > Capability Group · catalogue id`.

Every name, id and description is as published by Turbo EA Capabilities at commit `6774bf2ac45a1718d74f05b8b55ed85574f29499`, converted from YAML to Markdown.
