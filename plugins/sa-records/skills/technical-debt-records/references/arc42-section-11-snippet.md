### Conventions

- Written by the `technical-debt-records` skill; IDs global, zero-padded, never reused.
- Status, one per record: `Open` (Jira `ACEPTADA`), `Planned` (`PROYECTADA`), `In Progress` (`EN CURSO`), `Resolved` (`PAGADA`), `Won't Fix` (`BANCA ROTA`). The file carries the English word.
- Moves: `Open` / `Planned` → `In Progress` → `Resolved`; `Open` → `Won't Fix`; `Planned` → `Open`; never straight to `Resolved`; each a dated `## History` note.
- `Resolved` and `Won't Fix` stay in `/tdr/` and leave this table.
